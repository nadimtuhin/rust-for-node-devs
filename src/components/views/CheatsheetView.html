Rosetta Stone Syntax Cheatsheet

Quick syntax lookup comparing TypeScript and Rust side-by-side.

TypeScript Concept Rust Equivalent
const x = 5; let y = 10; let x = 5; let mut y = 10;
number i32, i64, u32, u64, f64, usize
string String (owned heap) or &str (borrowed slice)
null | undefined Option<T> (Some(val) | None)
throw new Error(...) Result<T, E> (Ok(v) | Err(e))
Array<T> / T[] Vec<T> (dynamic) or [T; N] (fixed)
