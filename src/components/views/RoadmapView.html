01 Toolchain, Installation & Cargo Essentials

roadmap.sh Milestone: Setup

In the Node.js universe, version managers like nvm or fnm manage Node runtimes while npm/pnpm handle package dependencies. In Rust, rustup is the unified toolchain manager that installs rustc, cargo, rust-analyzer, and cross-compilation targets.

Key Roadmap Concepts

  • rustup: Toolchain channels (stable, beta, nightly)
  • cargo init, cargo build, cargo check
  • rust-analyzer language server configuration
  • Playground vs Native compilation

02 Memory Management, Ownership & Borrowing

roadmap.sh Milestone: Core Philosophy

Node.js developers rely on V8's Mark-and-Sweep Garbage Collector (Orinoco/Scavenger) to reclaim unreferenced heap allocations. Rust eliminates GC runtime pauses through compile-time Affine Types and RAII (Resource Acquisition Is Initialization), where memory is deterministically dropped when its single owning variable exits scope.

Key Roadmap Concepts

  • Stack vs Heap allocations & cache locality
  • Single ownership rule & Move semantics
  • Shared (&T) vs Exclusive (&mut T) references
  • Non-Lexical Lifetimes (NLL) & lifetime annotations ('a)

03 Algebraic Types, Enums & Zero-Cost Error Handling

roadmap.sh Milestone: Data Structures

In TypeScript, union types and nullable types (null | undefined) are checked at compile time but erased at runtime, leaving programs vulnerable to TypeError: Cannot read properties of undefined. Rust has no null. Instead, it utilizes Algebraic Data Types (ADTs) with Option<T> and Result<T, E>, enforced through exhaustive pattern matching.

Key Roadmap Concepts

  • Structs (tuple, named, unit) & impl methods
  • Enums with data payloads (tagged unions)
  • match expressions & if let destructuring
  • The ? (try) operator for early error return
  • thiserror for domain errors & anyhow for applications

04 Traits, Monomorphization & Smart Pointers

roadmap.sh Milestone: Advanced Language

Unlike TypeScript interfaces, which rely on structural subtyping, Rust traits provide behavioral contracts with zero runtime overhead via static dispatch (monomorphization). When dynamic dispatch is required, dyn Trait produces a vtable. Smart pointers (Box, Rc, Arc, Mutex, RwLock) provide explicit shared ownership and interior mutability.

Key Roadmap Concepts

  • Traits: definition, derive macros (#[derive(Debug, Clone)])
  • Static dispatch (Generics + Trait bounds) vs Dynamic dispatch (Box<dyn Trait>)
  • Box<T> for heap allocation & recursive structures
  • Rc<T> vs Arc<T>: Single-threaded vs Thread-safe reference counting
  • RefCell<T> vs Mutex<T> / RwLock<T> interior mutability

05 Concurrency, Fearless Multi-Threading & Tokio

roadmap.sh Milestone: Concurrency & Async

Node.js utilizes a single-threaded libuv event loop where long-running CPU calculations block all incoming HTTP requests. In Rust, the Send and Sync marker traits mathematically guarantee that multi-threaded code is free of data races. Asynchronous Rust uses zero-cost state machines that only execute when polled by a work-stealing executor like Tokio.

Key Roadmap Concepts

  • OS threads (std::thread::spawn) vs Async green tasks (tokio::spawn)
  • Message passing with CSP channels (mpsc, broadcast, watch, oneshot)
  • Future trait, Pin<P>, and cooperative polling loops
  • Task budgeting, cooperative yield (tokio::task::yield_now), cancellation tokens

06 Web Services, Databases & Production Deployment

roadmap.sh Milestone: Ecosystem

Transitioning from Express/Fastify/NestJS to high-throughput Rust web microservices. The modern Rust production stack centers around Axum (built atop Tower and Hyper), compile-time checked SQL with SQLx, asynchronous ORM with SeaORM, high-performance serialization via Serde, and multi-stage cargo-chef Distroless Docker containers.

Key Roadmap Concepts

  • Web Frameworks: Axum 0.7+, Actix-web, Tower middleware
  • Databases: SQLx (compile-time SQL validation), SeaORM
  • Serialization: serde, serde_json with zero-copy deserialization
  • Production Containers: cargo-chef recipe caching & Distroless images (<20MB)
