Appendix 04 • Microservice Blueprint

Production Axum Microservice Architecture

From Express & Mongoose to Axum, Tower Middleware, SQLx connection pool, and graceful SIGTERM shutdown.

Canonical Project Layout

my-axum-service/
├── Cargo.toml
├── src/
│   ├── main.rs            # Entry point: binds TCP, initializes Tokio & tracing
│   ├── config.rs          # Strongly typed environment configuration
│   ├── state.rs           # Arc<AppState> (SQLx Pool, Redis client)
│   ├── routes/
│   │   ├── mod.rs         # Router aggregation
│   │   ├── health.rs      # GET /healthz
│   │   └── users.rs       # POST /api/users, GET /api/users/:id
│   └── models/
│       └── user.rs        # Serde structs & SQLx database row mappings
└── tests/
    └── api_tests.rs       # End-to-end integration tests
