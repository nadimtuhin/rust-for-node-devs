Appendix 07 • Artificial Intelligence

Building AI Agents in Rust

Why leading AI companies are migrating agent execution loops and token streaming gateways from Node.js/Python to Rust.

The Modern Rust AI Ecosystem

  • rig-core: Declarative LLM agent and tool framework with OpenAI, Anthropic, and local model support.
  • candle: Minimalist, zero-Python ML framework by Hugging Face running local models on Metal & CUDA.
  • tiktoken-rs: Blazing-fast BPE token counting without Python subprocess overhead.
  • qdrant: Production vector database written entirely in Rust for maximum memory efficiency.
