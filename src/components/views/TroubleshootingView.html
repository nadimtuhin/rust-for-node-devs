Appendix 09 • Diagnostics

Diagnostics, Flamegraphs & Profiling

Tools and step-by-step diagnostic workflows for identifying bottlenecks and undefined behavior.

The Diagnostic Toolkit

  • cargo clippy: Catches anti-patterns, non-idiomatic code, and performance traps.
  • cargo flamegraph: Generates interactive SVG flamegraphs of CPU time spent in functions.
  • cargo miri test: Interprets Rust code to catch undefined behavior and pointer violations.
  • tokio-console: Live interactive terminal dashboard for debugging async tasks and Tokio channels.
