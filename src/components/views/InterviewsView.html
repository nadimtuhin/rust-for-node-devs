Senior Systems Interview Q&A

Master the deep technical questions asked at companies like Cloudflare, Discord, AWS, and Figma.

Q1: What is the difference between String and &str in memory?

String is an owned, growable vector of UTF-8 bytes stored on the heap. Its stack representation is 24 bytes (pointer to heap buffer, capacity, and current length). In contrast, &str is a borrowed string slice consisting of only 16 bytes on the stack: a pointer to existing bytes (which can be on the heap, stack, or static binary data section) and length.

Q2: Why can't you hold a std::sync::MutexGuard across an .await point in Tokio?

When a future yields at an .await point, the Tokio runtime may resume that task on a different worker thread. Standard OS mutexes (like pthread_mutex) require the unlocking thread to be the exact same thread that acquired the lock. Holding an OS mutex across await violates Send bounds or can cause catastrophic deadlocks. The fix is using tokio::sync::Mutex or scoping the lock guard to drop before the await.
