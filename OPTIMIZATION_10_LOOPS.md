# AEO, SEO, GEO & Content Optimization Plan: 10 Adversarial Loops

## Overview
Comprehensive 10-round systematic optimization of `rust-for-node-devs` using Claude CLI as an adversarial auditor and strategist.

- **AEO (AI Engine Optimization)**: Optimizing for LLM retrieval, Perplexity, ChatGPT Search, Claude Search, Google AI Overviews, Gemini citations, semantic factual density, Q&A schemas, llms.txt, citation landmarks.
- **SEO (Search Engine Optimization)**: Technical SEO, JSON-LD structured data, Open Graph, meta titles/descriptions, semantic HTML, sitemap.xml, canonicals, robots.txt, Core Web Vitals readiness.
- **GEO (Generative Engine Optimization)**: Information gain, source authority attribution, benchmarks, concrete quantitative comparisons, verbatim code quotes, glossary citations, domain entity modeling.
- **Content Quality**: Eliminating shallow explanations, enriching architectural comparisons (V8 runtime vs Tokio, garbage collection vs RAII, libuv event loop vs work-stealing threadpool), code accuracy.
